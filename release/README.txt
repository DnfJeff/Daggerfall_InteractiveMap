DAGGERFALL INTERACTIVE MAP  {{VERSION}}  (desktop)
====================================================

The in-game map, freed from the game: a zoomable map with every town's street layout, shop names,
roads, encounters, and a notebook that remembers what you learn across playthroughs.

START
  Double-click "Daggerfall Interactive Map.exe". Nothing to install.
  Needs Windows 10/11 (uses the WebView2 runtime that ships with Windows).

FIRST RUN
  "Open the map now" uses the map data built into the app: no game files needed.
  Or point it at your own Daggerfall data (the ARENA2 folder, contains MAPS.BSA) and, optionally:
    Daggerfall Unity saves   %USERPROFILE%\AppData\LocalLow\Daggerfall Workshop\Daggerfall Unity\Saves
    Daggerfall Online saves  %APPDATA%\Daggerfall JavaScript\Saves
    Daggerfall Unity install (lists mods; reads the Basic Roads mod for the roads layer)
  Tip: copy a path above and paste it into the folder picker's address bar.

YOUR DATA
  Notes, markers, profiles and settings are kept in the "data" folder next to the .exe.
  Move or copy the whole folder and your data comes along.
  To share the app WITHOUT your notes, share just the .exe and this README.
  Back up from inside the app: Data & backups -> Export, or set a backup folder.

CREDITS
  Game data is read from your own Daggerfall install; none is included.
  Shop/tavern name tables, NameGen, enemy and encounter tables come from Daggerfall Unity
  (MIT, (C) Daggerfall Workshop). Roads come from the Basic Roads mod (Hazelnut) when installed.
